# Mission Room

Mission Room is a collaborative, real-time incident-response workspace where human operators and specialized AI agents investigate evolving incidents together.

Unlike static incident-analysis systems, Mission Room treats incidents as continuously changing environments. New information can invalidate previous findings, trigger reassessments, and create disagreements between agents.

## Key Features

* 🤖 **Multi-Agent Investigation** — Specialized AI agents investigate different aspects of the same incident.
* 🌐 **Shared Mission Context** — All agents operate within a common, continuously updated incident context.
* 🔎 **Knowledge Retrieval with Moss** — Agents retrieve relevant knowledge and evidence through Moss.
* ♻️ **Stale Finding Detection** — The system identifies findings that may no longer be valid when new information arrives.
* 🔄 **Automatic Reassessment** — Stale findings trigger agents to revisit and update their conclusions.
* ⚖️ **Visible Agent Disagreement** — Conflicting conclusions are surfaced instead of being silently merged or hidden.
* 🙋 **Human-in-the-Loop** — When evidence is insufficient, Mission Room identifies missing information and asks the human operator for clarification or additional data.
* 🧑‍✈️ **Human Final Authority** — AI agents investigate and recommend; the human operator makes the final decision.
* 📝 **Complete Investigation Record** — Actions, evidence, findings, disagreements, reassessments, and decisions are recorded.
* 📊 **Evidence-Backed Reporting** — The system generates a final report grounded in the investigation history and supporting evidence.

## Core Philosophy

AI investigates. Humans decide. Evidence persists.

Mission Room is designed for incident response where the situation changes faster than a static analysis workflow can handle, enabling multiple AI investigators to reason together while keeping uncertainty, disagreement, and human judgment visible.
